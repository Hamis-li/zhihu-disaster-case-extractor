# 知危鉴 · 1分钟演示视频脚本（含旁白台词）

## 录制工具
- Windows 自带：Win+G 打开游戏栏 → 录屏
- 或用 OBS Studio（免费，画质更好）
- 录制分辨率：1920×1080，30fps

## 录制前准备
1. 打开 Demo：https://zhihu-disaster-case-extractor-kqojwnlr7fdrzhesgew7ma.streamlit.app
2. 确认已加载 Access Secret（侧边栏不需要手动输入）
3. 浏览器全屏 F11，隐藏书签栏
4. 先空跑一遍流程，确保搜索和萃取都能正常返回结果

## 视频脚本（约 60 秒）

> 旁白用「」标注，直接照念即可。语速适中，每段操作前念。

---

### 0-5秒：开场
- **画面**：Demo 首页静止，展示顶部 Banner
- **旁白**：「知危鉴，灾害应急案例AI萃取助手。让每一条应急经验，都有据可查。」

### 5-15秒：第一层 智能检索
- **操作**：点击「城市内涝」快捷按钮
- **画面**：搜索结果列表出现
- **旁白**：「输入灾害关键词，一键检索知乎优质应急内容，支持权威等级标识。」

### 15-30秒：第二层 案例萃取
- **操作**：勾选 2 篇文章 → 点击「萃取选中案例」
- **画面**：进度条 → 四维知识卡片展示
- **旁白**：「AI按事件概况、风险因素、应急处置、经验教训四维萃取，每条结论附原文证据，从机制上防幻觉。」

### 30-40秒：第三层 案例分析
- **操作**：点击「生成时间线」
- **画面**：时间线 + 对比表 + 完整度图
- **旁白**：「多案例横向对比、事件时间线、共性分析，一眼看清风险和处置差异。」

### 40-50秒：第四层 AI综合复盘
- **操作**：点击「生成复盘报告」→ 点击「下载 Markdown 报告」
- **画面**：复盘报告 → 下载文件
- **旁白**：「一键生成结构化复盘报告，支持导出Markdown，可离线复盘与分享。」

### 50-60秒：结尾
- **画面**：滚动到底部，展示防幻觉说明
- **旁白**：「所有结论严格基于原文证据，未提及内容明确标注。知乎黑客松2026，知识炼金场，应急有我团队。」

---

## 录制技巧
- 每段旁白念完再操作，操作时停顿0.5秒让画面跟上
- 用鼠标指向当前讲解的区域
- 念错了就从头来，1分钟很短，不要拼接
- 导出格式 MP4
